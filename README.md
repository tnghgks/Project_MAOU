# 마왕 채널 (MAOU CHANNEL)

> 파탄난 마왕성의 마지막 수익 모델 — 용사를 스타로 키워 방송으로 먹고사는 라이브 스트리밍 액션 게임.

**▶ 플레이: https://tnghgks.github.io/Project_MAOU**

플레이어는 채널을 개국한 마왕이다. 성문 앞에 도착한 용사를 쫓아내는 대신 방송의 주인공으로 세우고,
몬스터 웨이브를 편성해 판을 깔은 뒤 그 안에서 용사를 직접 조작해 시청자를 끌어모은다.

- **용사가 죽으면 방송이 끝난다** — 살려야 한다.
- **용사가 안전하면 아무도 안 본다** — 위험해야 시청자가 는다.

## 게임 방법

```
타이틀 → [편성] 웨이브 짜기 → [방송] 실시간 전투 → [정산] → [상점] 강화·카드 구매 → 다음 화 → 최종화 → 엔딩
```

- **목표** — 몬스터 처치 골드 + 시청자 후원 골드로 화별 목표 골드(1화 1,000G · 2화 3,000G · 3화 5,000G)를 채우면 보스가 등장하고, 격파하면 그 화를 클리어한다. 최종화의 마왕 **그림하르트**를 쓰러뜨리면 엔딩.
- **위험도** — 용사 체력이 낮을수록 시청자 증가율이 오른다 (😴 노잼 / 🙂 볼만함 / 🔥 꿀잼 / 💀 벼랑끝).
- **시청자 요청** — 채팅으로 뜨는 요구를 제한시간 안에 달성하면 시청자 ×1.35, 실패하면 ×0.85.
- **후원 이벤트** — 전투가 멈추고 QWER 리듬 미니게임이 열린다. 판정에 따라 시청자 배율과 강화 카드 등급이 갈린다.
- **종료 조건** — 용사 사망, 또는 시청자 1명 이하로 떨어진 뒤 10초 안에 회복 실패 시 방송 종료.
- **엔딩** — 최종화 클리어 시 키워낸 용사의 최대 체력을 기준으로 BAD / BEST / HIDDEN 3분기.

## 조작

| 입력 | 동작 |
|------|------|
| `W` `A` `S` `D` | 용사 이동 |
| `Shift` | 대시 (짧은 무적) |
| 공격 | **자동** — 사거리 안에 들어오면 알아서 벤다 |
| `Space` | 다음 웨이브 즉시 호출 |
| `1` `2` `3` `4` | 스킬 시전 |
| `Q` `W` `E` `R` | 후원 리듬 노트 입력 |
| `Esc` | 일시정지 / 메뉴 |

## 로컬 실행

**요구 사항**: Node.js 20 이상

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 확인
npm test         # 테스트
```

> 컷씬 영상은 외부 버킷에서 로드된다. 로컬에서 재생하려면 `.env.example`을 복사해 `.env`를 만들고 `VITE_BUCKET_BASE_URL`을 채운다. 없어도 게임 진행에는 지장이 없다(텍스트 카드로 대체).
